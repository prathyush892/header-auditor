# 2026-11-09: Initial CLI + roadmap

## Built
- Python CLI that grades 9 security-header areas, scores 0–100 and assigns a letter grade.
- `--json` output and a `--min-grade` exit code so it can gate CI.
- Unit tests per check; integration tests against a mock server on 127.0.0.1.

## Design decisions worth explaining
- **Checks are pure functions** (`headers → Finding`) separate from networking, so
  every rule is unit-testable without HTTP.
- **Not-applicable checks are excluded from the score** (e.g. HSTS over plain
  HTTP), so a site isn't punished for things that can't apply.
- **4xx/5xx responses are still audited**, because error pages are often where
  headers go missing.
- **Only http/https schemes are accepted**, which blocks `file://` style abuse.
